It does not contain proprietary or confidential company code.\n\n---\n\n## 🛠 Technology Stack\n\n- **Java 11+** - Programming language\n- **REST Assured 5.x** - HTTP client\n- **TestNG 7.8+** - Test framework\n- **Cucumber JVM 7.14+** - BDD framework\n- **Jackson 2.16+** - JSON/POJO serialization\n- **JSON Schema 2.2+** - Response validation\n- **Allure 2.21+** - Test reporting\n- **Maven 3.8+** - Build tool\n\n---\n\n## 🏗 Architecture\n\n```\nGherkin Feature Files\n    ↓\nCucumber Step Definitions\n    ↓\nAPI Client\n    ↓\nRequest Specification\n    ↓\nREST Assured\n    ↓\nHTTP Request\n public ApiClient(String baseUrl) {\n        this.requestSpec = RestAssured.given()\n            .baseUri(baseUrl)\n            .contentType(ContentType.JSON);\n    }\n    \n    public Response get(String endpoint) {\n        return requestSpec.get(endpoint);\n    }\n    \n    public Response post(String endpoint, Object body) {\n        return requestSpec.body(body).post(endpoint);\n    }\n}\n```\n\n### POJO Model\n\n```java\npublic class User {\n    @JsonProperty(\"id\")\n    private Integer id;\n    \n    @JsonProperty(\"email\")\n    private String email;\n    \n    @JsonProperty(\"first_name\")\n    private String firstName;\n    \n    // Getters and Setters\n}\n```\n\n### Test Class\n\n```java\npublic class UserApiTests {\n    private ApiClient apiClient;\n    \n    @BeforeClass\n    public void setup() {\n        apiClient = new ApiClient(\"https://reqres.in/api\");\n    }\n    \n    @Test(groups = \"smoke\")\n    public void testGetUser() {\n        Response response = apiClient.get(\"/users/1\");\n        \n        assertThat(response.statusCode()).isEqualTo(200);\n        User user = response.as(User.class);\n        assertThat(user.getId()).isEqualTo(1);\n    }\n    \n    @Test(groups = \"smoke\")\n    public void testCreateUser() {\n        User newUser = new User();\n        newUser.setEmail(\"test@example.com\");\n        newUser.setFirstName(\"John\");\n        \n        Response response = apiClient.post(\"/users\", newUser);\n        assertThat(response.statusCode()).isEqualTo(201);\n    }\n}\n```\n\n---\n\n## 📊 Features\n\n✅ HTTP methods (GET, POST, PUT, DELETE, PATCH)  \n✅ POJO serialization with Jackson  \n✅ JSON schema
